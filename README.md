# Sales & Revenue Analysis Dashboard

## Project Overview

The Sales & Revenue Analysis Dashboard is a data visualization project developed using Microsoft Power BI. It helps analyze sales performance, revenue trends, product performance, and regional sales using interactive charts, KPI cards, and filters.

## Objective

The main objective of this project is to transform sales data into meaningful business insights and help users understand sales performance through an interactive dashboard.

## Tools & Technologies Used

* Microsoft Power BI Desktop
* Microsoft Excel
* Data Visualization
* Data Analysis

## Dataset Description

The project uses an Excel dataset containing 100 sales records.

The dataset includes the following columns:

* Order ID
* Date
* Product
* Category
* Region
* Quantity
* Unit Price
* Revenue

Revenue is calculated using the formula:

**Revenue = Quantity × Unit Price**

## Key Features

* Total Revenue KPI card
* Total Orders KPI card
* Total Quantity KPI card
* Revenue analysis by product category
* Monthly revenue trend analysis
* Top-performing product analysis
* Regional sales analysis
* Interactive region slicer for filtering data

## Project Workflow

1. Created a sales dataset in Microsoft Excel.
2. Imported the Excel dataset into Power BI Desktop.
3. Checked the data fields and prepared the data for visualization.
4. Created KPI cards to display important sales metrics.
5. Designed charts to analyze categories, products, and revenue trends.
6. Added interactive slicers for regional analysis.
7. Arranged and formatted the visuals to create an interactive dashboard.

## Expected Outcome

The dashboard provides a clear overview of sales and revenue performance. It helps identify high-performing products, compare regional performance, and understand revenue trends.
